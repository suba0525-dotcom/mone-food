# MONÉ FOOD — 食事記録と食費管理

## できること
- 日付ごとに食べたもの、朝食/昼食/夕食/間食/夜食/飲み物、時刻、金額、買い方、メモを記録
- 1日の食事記録数、朝昼晩の記録有無、当日の食費を表示
- 1日と1か月の食費予算、残額/超過、月間食費を表示
- 日付を移動して過去の食事を確認
- 月間カレンダーで記録がある日とその日の食費を確認
- 月曜〜日曜の週間データ（合計食費・記録数・1日平均・日別棒グラフ）
- レシートAI読み取りで店名・日付・合計金額を補助入力（AI接続設定が必要）

## 保存とプライバシー
食事記録はブラウザのlocalStorage内だけに保存し、クラウド家計簿同期はしません。ブラウザのデータ消去、プライベートモード、端末/ブラウザ変更でデータが失われる可能性があるのでバックアップを定期的に書き出してください。
AIレシート読み取り時だけ、画像はブラウザで縮小され、設定したCloudflare Worker経由でOpenAI APIへ送信されます。MONÉ自体は画像を保存しません。AI提供元側のデータ取扱いポリシーは別途確認してください。写真に個人情報が含まれる場合は注意してください。

## AI読み取りの料金
OpenAI APIはChatGPTのサブスクリプションとは別料金の従量課金です。利用するモデル・画像の解像度・トークン数で料金が変わります。使用開始前に公式の最新料金表を確認し、低い予算上限を設定してください。
- https://platform.openai.com/docs/pricing
- https://platform.openai.com/docs/guides/your-data

## AIを有効にする（任意）
1. OpenAI API PlatformでAPIキーを作成し、課金と利用上限を設定します。
2. CloudflareでWorkerを作り、`worker.js`の内容をデプロイします。
3. WorkerのSecret `OPENAI_API_KEY` にAPIキーを保存します。`index.html`には絶対にAPIキーを入れないでください。
4. Workerの環境変数 `ALLOWED_ORIGIN` にアプリのホスト元を設定します（例 `https://your-app.pages.dev`。末尾スラッシュなし）。
5. `index.html`をHTTPS対応の静的ホスト（Cloudflare Pages等）に置きます。`file://`で開くと動作しないことがあります。
6. アプリの「レシートから入力」でWorker URLを設定してテストします。

## 重要
- WorkerはOriginチェックとサイズ制限を行いますが、Originだけでは強固な認証になりません。公開前にCloudflareのレート制限などを追加し、API利用上限を設定してください。Worker URLを不用意に公開しないでください。
- レシートの合計金額は食べた内容そのものではありません。レシートから読み取った場合は食べたものを編集し、確認してから保存してください。
- このパッケージはウェブアプリのスターターです。App Store配信済みのネイティブアプリではありません。

## この版の変更点
- 画面下部のバックアップ書き出し/復元ボタンは削除しました。
- カレンダーで過去の日付を選べます。記録のある日には印と日別食費が表示されます。
- 週間データは月曜日〜日曜日で、週合計・食事記録件数・7日平均食費・日別食費グラフを表示します。


## iPhoneアプリとしてホーム画面に追加（PWA）

このフォルダ一式をHTTPS対応の静的ホスティングに公開すると、iPhoneのSafariからホーム画面に追加できます。

1. フォルダ内のファイルをまとめて静的ホスティングにアップロードする。
2. 発行されたHTTPSのURLをiPhoneのSafariで開く。
3. 共有ボタン →「ホーム画面に追加」→「追加」。

食事データは引き続きブラウザ内に保存され、クラウド同期はしません。SafariのWebサイトデータを消すと記録が消える可能性があるので注意してください。
